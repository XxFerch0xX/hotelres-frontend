# HotelRes Frontend

Frontend del sistema HotelRes desarrollado con React + Vite.

## Módulos
- Dashboard con estadísticas
- Gestión de Usuarios (CRUD)
- Gestión de Clientes (CRUD)
- Gestión de Habitaciones y Tipos (CRUD)
- Gestión de Reservas (crear, check-in, check-out, cancelar)
- Facturación (emisión de facturas)
- Finanzas (gastos operativos)

## Instalación

```bash
npm install
```

## Ejecución

Primero levantar el backend (puerto 8000), luego:

```bash
npm run dev
```

El frontend se levanta en `http://localhost:5173`.

## Tecnologías
- React 18
- Vite
- React Router
- Axios
